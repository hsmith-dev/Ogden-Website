WHAT'S ON BOARD

Six modules. One shared codebase.

01

Autonomous Backlog

A real Kanban board per project. Assign a task to a persona, flip the project to autonomous, and watch it move — or click Run now and drive it yourself.

02

A Full AI Crew

Every persona is yours to tune — name, avatar, system prompt, model, temperature, tool access. Talk to the whole team at once, or pull one aside 1:1.

03

Any Model, Anywhere

OpenAI, Anthropic, Gemini, a self-hosted Ollama box, or any OpenAI-compatible endpoint — mixed freely across personas in the same project.

04

Human-in-the-Loop

Turn on approval gates and every run lands on its own branch. Review the real diff, then approve & merge or reject with feedback that flows into the retry.

05

Full Audit Trail

Per-call token and cost tracking, budget caps that actually stop runaway spend, run history, and a live activity log for every task.

06

Sandboxed & Governed

Every project gets its own isolated git workspace. Role-based access, org-level tenant isolation, and non-root containers by default.
