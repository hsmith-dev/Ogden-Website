Free & open source, local app

One browser tab. Every AI agent you already use.

In the spirit of herdr, Ogden Agents keeps many projects and many chats in one place and shows which are working, waiting on you, or idle. It wraps Claude Code, Antigravity, Codex and Grok through the Agent Client Protocol, plus local models, so you stop juggling a terminal tab per agent. Each one asks before it runs a command or edits a file, and you answer with a card.

What's inside

A home base, not another chat window.

All of it is in one codebase you can read, change, and run on your own computer.

01

Every agent, one inbox

Use Claude Code, Antigravity, Codex, Grok, or a local model, each with its own persistent chats and model choice. The sidebar shows at a glance which are working, waiting on you, or idle, and you get a preview before handing a conversation to another agent.

02

Permission cards

Each agent asks before it runs a command or edits a file, and you answer with a card. Nothing happens unattended unless you choose Auto for an agent that supports it.

03

BMad planning & the Board

Turn on BMad Planning, a live ticket Board, and Retrospectives separately for each project, so a project only gets as much process as it needs.

04

Make it yours

Choose the Ogden, Forest, or Ember appearance preset, or build a fully custom theme with paired light/dark colors, contrast validation, and JSON import/export to share it.

OgdenForestEmber Custom theme
05

Build tickets safely

Tickets build in their own worktree. Inspect the verification results and approve the merge yourself, or let Claude Code run unattended where a supported sandbox is available.

06

Orchestrate

Coordinate a manager and worker agents from Orchestrate, with approval per instruction by default, recorded activity, and a Stop you can hit any time.

Run it

Your computer, your data.

Ogden Agents is for one user on one computer: the server only listens on 127.0.0.1, there's no telemetry, and nothing leaves your machine except what you explicitly send to an agent you've signed in to.

Full setup guide →

From a checkout

Node 24+ · pnpm

Clone the repo, install, and start it. The app opens in your browser at a one-time launch link.

$ git clone https://github.com/hsmith-dev/ogden-agents.git
$ cd ogden-agents && pnpm install
$ pnpm start

Desktop app

macOS · Windows · Linux

Ogden Agents also ships as a desktop app that needs no Node and no terminal. Prebuilt downloads and no-terminal start scripts land on the GitHub Releases page as v1 finishes rolling out — check there for what's currently available.
