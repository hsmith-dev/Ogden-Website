Setup guide

Get Ogden Agents running.

From a checkout to your first permission card, in a few minutes.

1

Prerequisites

Node.js 24 or later and pnpm, plus at least one agent you can sign in to: a Claude Code or Antigravity subscription account, an OpenAI API key for Codex, an xAI API access token for Grok, or a local model server you already run. Ogden Agents can install most of these for you from Settings > Agents.

2

Clone and start it

Clone the repository, install dependencies, and start the app. It builds, starts a local server bound to 127.0.0.1, and opens your browser to a one-time launch link.

git clone https://github.com/hsmith-dev/ogden-agents.git cd ogden-agents pnpm install pnpm start

Your projects, chats, and settings persist across restarts in your OS's per-user data folder (for example ~/Library/Application Support/ogden-agents on macOS). Nothing is written into your own repos.

3

Sign in to an agent

Open Settings > Agents and install the ones you want. Claude Code and Antigravity can sign in with your own subscription account or an API key. Codex and Grok are API-key only, by each provider's own terms. A local model needs no account at all — it talks to a server on your own computer (or any OpenAI-compatible address) through OpenCode. Keys and tokens are kept in your computer's keychain and go only to that agent's own process.

4

Permission cards

Start a chat with any agent and work normally. Before it runs a command or edits a file, it stops and shows you a permission card; you approve, deny, or send feedback. Developer mode adds Auto and Skip-all modes for agents that support running unattended.

5

Turn on planning

Per project, turn on BMad Planning, the live ticket Board, and Retrospectives as you need them. Build tickets in their own git worktree, review the verification results, and approve the merge yourself, or let a supported sandbox run unattended.

6

Desktop app & other ways to run it

Prefer no terminal at all? Ogden Agents also ships as a desktop app for macOS, Windows, and Linux, and as double-click start scripts that fetch the app for you. These roll out alongside the v1 release — see the Releases page for what's currently available, and the README for the exact, up-to-date steps for every platform.

7

How it keeps your computer to itself

The server only answers 127.0.0.1, there's no remote access and no telemetry, and each browser tab gets its own token instead of a cookie. It's built for one user on one computer, not a shared or multi-tenant deployment. The security & privacy doc in the repository walks through exactly what the app can and can't do on your machine.

8

Getting help

The GitHub README is the source of truth for setup, every platform's run instructions, and what's finished for v1. Open an issue on GitHub, or write to hello@harrisonsmith.ai with questions about this site.
